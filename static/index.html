System Architecture, Topology & Dual-Mode Operation

Hardware interconnects, communication layers, and fault-tolerant architecture.

The Lighthouse Pool automation platform coordinates physical pool equipment, low-voltage communication buses, high-voltage relays, and cloud services into a unified, responsive interface. Designed for continuous headless operation on a Raspberry Pi, the system acts as a reliable intermediary between the local pool equipment pad and web/voice clients.

Communication Layer Architecture

  • Local Protocol Bridge: Connects to Pentair IntelliCenter over native TCP socket (Port 6681) or WebSocket (Port 6680) via pyintellicenter.
  • mDNS Zero-Configuration: Broadcasts multicast DNS discovery requests (_intellicenter._tcp.local) to identify panel IP and port dynamically without requiring static IP DHCP reservations.
  • Keepalive Heartbeats: Sends non-blocking ping requests every 90 seconds. If socket drops or panel reboots, a backoff auto-reconnect cycle restores state seamlessly.
  • Bidirectional Synchronization: Listens for asynchronous NotifyList telemetry frames, updating temperatures, water flow, salt salinity, and relay states within milliseconds.

Dual-Mode Execution Model

  • Panel Synchronized Mode: Engaged whenever the IntelliCenter motherboard is reachable over the local network. Commands write directly to the panel via SETPARAMLIST, and telemetry mirrors hardware readings.
  • Simulation Digital Twin Mode: When the physical panel is unreachable (network maintenance or winterization), the system falls back to a high-fidelity local simulation model. All UI switches, schedules, 3D animations, and voice assistants remain fully interactive.
  • Zero-Downtime Transition: When the panel reconnects, the system reconciles hardware state automatically and pushes configured defaults.

Hydraulics, Water Body Modes & Safety Controls

Water circulation loops, motorized valve actuation, and emergency shutdown procedures.

The facility features a dual-body shared equipment configuration where a single filtration and heating system serves both the primary pool basin and the elevated perimeter-overflow spa. Motorized 24VAC 3-way valve actuators control hydraulic routing.

Pool Mode Hydraulics (Normal Filtration)

Designed for daily filtration, surface skimming, and water feature presentation:

  • Suction Actuator (Intake): Rotates to draw 80% water from the main pool drain/skimmers and 20% from the spa drain.
  • Return Actuator (Discharge): Rotates to deliver 80% discharge water into the spa return jets, with 20% to pool returns.
  • Spillway Overflow: The net positive return to the spa causes clean, filtered water to continuously spill over the decorative weirs into the pool basin, creating a natural aeration cascade.
  • Default RPM: 2200 RPM (~45 GPM) providing 2.4 complete water turnovers per day at 480 Watts consumption.

Spa Mode Hydraulics (Hydrotherapy & Rapid Heating)

Isolates the spa basin for elevated temperature retention and jet velocity:

  • Suction Actuator (Intake): Rotates to draw 80% water directly from the spa bottom drain, minimizing heat loss to the cold pool.
  • Return Actuator (Discharge): Directs 80% heated water back to the spa hydrotherapy return manifold.
  • Thermostat Activation: Automatically engages the pool gas heater with a target setpoint of 102°F.
  • Pump Dynamics: Main VSR pump ramps up to circulate the isolated spa volume through the heat exchanger.
Actuator Cam Timing & Valve Safety: Pentair Compool / CVA-24 motorized actuators take approximately 24 seconds to complete a 180° rotation. The IntelliCenter firmware incorporates an automatic soft-delay when toggling modes to prevent hydraulic line hammering and cavity cavitation.

Safety Shutdown: "All Off" Emergency Interlock

Clicking the red All Off button in the application header or saying "Turn off everything" executes an immediate emergency equipment sequence:

  1. De-energizes the gas heater ignition circuit (opening the fireman's switch).
  2. De-energizes high-voltage relays for all water features (deck jets, firepit spillways, blower).
  3. Switches off underwater pool and spa LED illuminators.
  4. Ramps down and stops both variable-speed pumps (Main VSR and Features VSR).

Variable-Speed Pump Scheduling Engine

Configuring automated filtration windows, pump affinity curves, and freeze protection.

Variable-speed pumps consume significantly less electrical energy at lower speeds due to the Pump Affinity Laws (Power scales with the cube of speed: $\text{Power} \propto \text{RPM}^3$). Running a pump at 1725 RPM consumes only 12.5% of the power required at 3450 RPM.

Scheduling Engine Operation

  • Local Timezone Evaluation: The background controller thread evaluates schedule rules every 10 seconds against the local timezone (America/New_York).
  • Multi-Window Filtration: Add discrete runs for specific days of the week, defining start time (HH:MM), stop time (HH:MM), and target RPM.
  • Midnight Wrap-Around: Runs spanning midnight (e.g. 20:00 to 04:00) are handled gracefully without interruption.
  • Manual Override Priority: If a user manually changes pump speed or mode during an active schedule window, the manual override remains in effect until the next scheduled transition.

Voice Assistant ("Talk to the Pool") & Iggy the Iguana

Natural language understanding, multimodal vision, and personality tuning.

Iggy is an integrated AI assistant powered by Google Gemini (gemini-2.5-flash). Iggy understands natural pool commands, reports water temperature, and controls circuits through structured function calling.

Audio Pipeline & VU Meter

  • Local Hardware Mic: Uses ALSA to capture audio from the USB webcam microphone connected directly to the Raspberry Pi.
  • Voice Activity Detection (VAD): Monitors live audio RMS levels. When speech exceeds the configured threshold (default 650 RMS) for over 350ms, recording begins automatically.
  • Silence Detection: 900ms of consecutive silence marks the end of speech, triggering Gemini transcription.
  • Speech Output: Generates natural voice responses using Google Text-to-Speech (gTTS) and outputs audio over the local HDMI speaker.

Iggy Personalities

  • Classic: Friendly, helpful poolside assistant with a light Florida accent.
  • Surfer: Laid-back, sun-soaked enthusiast who loves waves, swells, and relaxation.
  • British Butler: Formal, courteous estate manager ensuring impeccable pool etiquette.
  • Pirate: Swashbuckling captain treating the pool as the open seas.
  • Deadpan: Dry, witty, slightly sarcastic observer of pool life.
  • Custom: Enter custom prompt instructions in the Voice tab.

Amazon Alexa Smart Home v3 Skill Integration

Controlling your pool using Amazon Echo and the Alexa Smart Home API.

The application implements an Alexa Smart Home v3 directive endpoint at https://pool.shobots.party/alexa. All discovered circuits, water features, pumps, and thermostats are exposed as native Alexa devices.

AWS Lambda Smart Home Forwarder

Create an AWS Lambda function running Python 3.12 with the Alexa Smart Home trigger, forwarding directives to your endpoint:

import json, urllib.request

ENDPOINT_URL = "https://pool.shobots.party/alexa"
BEARER_TOKEN = "YOUR_ALEXA_BEARER_TOKEN"

def lambda_handler(event, context):
    req = urllib.request.Request(
        ENDPOINT_URL,
        data=json.dumps(event).encode("utf-8"),
        headers={
            "Content-Type": "application/json",
            "Authorization": f"Bearer {BEARER_TOKEN}"
        }
    )
    with urllib.request.urlopen(req, timeout=10) as response:
        return json.loads(response.read().decode("utf-8"))

Raspberry Pi Setup, Security & Service Commissioning

Complete deployment procedure from clean OS installation to background daemon.

Step 1: Install System Packages

sudo apt update && sudo apt install -y git python3 python3-pip ffmpeg alsa-utils curl
sudo usermod -aG audio,video $USER

Step 2: Clone Repository & Install Python Libraries

mkdir -p ~/projects && cd ~/projects
git clone https://github.com/markirgang/Pool.git
cd Pool
pip install --break-system-packages -r requirements.txt

Step 3: Configure systemd User Service

Create a persistent systemd service ensuring the pool controller starts on boot and restarts if an error occurs:

mkdir -p ~/.config/systemd/user
cat << 'EOF' > ~/.config/systemd/user/pool.service
[Unit]
Description=Lighthouse Pool IntelliCenter Server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=%h/projects/Pool
ExecStart=/usr/bin/python3 server.py --port 2490 --host 0.0.0.0
Restart=always
RestartSec=4s
Environment="PYTHONUNBUFFERED=1"

[Install]
WantedBy=default.target
EOF

systemctl --user daemon-reload
systemctl --user enable --now pool.service
loginctl enable-linger $USER

Step 4: Cloudflare Tunnel for Public Access

Install and authenticate cloudflared to route public traffic securely without port forwarding:

curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb
sudo dpkg -i cloudflared.deb
cloudflared tunnel route dns shobots pool.shobots.party

Systematic diagnostic procedures for resolving network, hardware, audio, and visual issues.

App displays "SIMULATION MODE" IntelliCenter IP unreachable or mDNS multicast blocked by router. Check Hardware tab; run ping <panel-ip> from Pi. Enter static IP in Hardware tab, check port 6681, or verify panel is powered on.

Hardware Checklist & Prerequisites

Required and optional hardware for a robust, 24/7 dedicated pool controller.

Required Components

  • Raspberry Pi Single-Board Computer: Raspberry Pi 4 Model B (2GB, 4GB, or 8GB) or Raspberry Pi 5.
  • Storage: 32 GB or 64 GB MicroSD card (SanDisk Extreme, Samsung EVO Plus, Class 10 / A2 rated) or USB 3.0 NVMe SSD.

  • Local Network Link: Cat5e/Cat6 Gigabit Ethernet cable to your router or 2.4/5GHz Wi-Fi (must be on the same subnet/VLAN as the Pentair IntelliCenter).

Optional Voice & Vision Components

  • USB Webcam with Mic: Standard UVC webcam (Logitech C920, C270, or similar) connected to a USB 3.0 port for Iggy camera vision and voice detection.
  • Audio Output: USB mini speaker, 3.5mm analog speaker (Pi 4), or HDMI monitor/TV for spoken voice responses.
  • Enclosure & Cooling: Flirc aluminum passive case or active cooling fan case for sustained outdoor/patio operation.

Flash Raspberry Pi OS (Headless Setup)

Prepare the MicroSD card using Raspberry Pi Imager with preconfigured SSH and Wi-Fi.

  1. Download and install Raspberry Pi Imager on your PC or Mac from raspberrypi.com/software.
  2. Insert the MicroSD card into your computer's card reader.
  3. Launch Raspberry Pi Imager:
    • Raspberry Pi Device: Choose Raspberry Pi 4 or Raspberry Pi 5.
    • Operating System: Choose Raspberry Pi OS (64-bit) (Bookworm recommended; Debian based).
    • Storage: Select your MicroSD card.
  4. When prompted "Would you like to apply OS customization settings?", click Edit Settings:

Power on the Raspberry Pi and connect remotely over your local network.

  1. Insert the MicroSD card into the Raspberry Pi's card slot.
  2. Connect your Ethernet cable (if using wired networking) and plug in the USB-C power supply.

When prompted with "Are you sure you want to continue connecting (yes/no/[fingerprint])?", type yes and enter your password.

09

Configure Persistent systemd Background Service

Ensure the pool controller starts automatically on boot and auto-restarts if a fault occurs.

Create the systemd user service directory and service unit definition:

mkdir -p ~/.config/systemd/user
cat << 'EOF' > ~/.config/systemd/user/pool.service
[Unit]
Description=Lighthouse Pool IntelliCenter Server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=%h/projects/Pool
ExecStart=/usr/bin/python3 server.py --port 2490 --host 0.0.0.0
Restart=always
RestartSec=4s
Environment="PYTHONUNBUFFERED=1"

[Install]
WantedBy=default.target
EOF

Reload the systemd user daemon, enable the service on boot, and start it immediately:

systemctl --user daemon-reload
systemctl --user enable --now pool.service
loginctl enable-linger $USER
Why loginctl enable-linger $USER is critical: By default, systemd user services stop when you disconnect your SSH session. Enabling linger allows user services to launch at system boot and remain running 24/7 headlessly without an active user login.

Check the service status to verify it is running cleanly:

systemctl --user status pool.service
10

Remote Access via Cloudflare Tunnel (Optional)

Expose your pool controller securely to the internet without opening inbound firewall router ports.

Download and install cloudflared for ARM64:

curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb
sudo dpkg -i cloudflared.deb

Authenticate cloudflared and create your tunnel:

cloudflared tunnel login
cloudflared tunnel create pool
cloudflared tunnel route dns pool pool.shobots.party

Install cloudflared as a system service so it stays running 24/7:

sudo cloudflared service install
sudo systemctl enable --now cloudflared
